# LiDB

LiDB is a **Learning Implementation Database**: a small database project built to help me understand how databases work under the hood.

This is a learning implementation, not a production-ready database. I am reading about how other databases are designed and using those ideas to build something simple, easy to implement, and easy to understand. The project is also a way for me to strengthen my Rust skills through a small, hands-on passion project.

## What this project is for

- Learning how the pieces of a simple database fit together
- Exploring concepts such as storage, tables, schemas, SQL lexing, parsing, binding, and execution
- Practising Rust by building each part incrementally
- Keeping the implementation approachable enough to read, experiment with, and change

LiDB is intentionally modest in scope. It may eventually grow as I learn more, but simplicity and understanding are more important here than completeness or performance.

## About me

I am a mechatronics engineer with a background in embedded systems, MES web development, data engineering, and AI systems. LiDB is a small personal project where I can explore database internals and continue developing my Rust skills.

## Status

This project is actively being developed as a learning exercise. APIs, behavior, and implementation details may change as my understanding evolves.
